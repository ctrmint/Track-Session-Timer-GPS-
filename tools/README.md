# Tools

- `geometry_reference.py`: dependency-free reference line-intersection logic used by early host tests.
- `create_labels.py`: previews or creates the standard repository labels using GitHub CLI.
- `create_issues.py`: previews the backlog snapshot and idempotently creates missing issue titles.
- `validate_tracks.py`: validates the Draft 2020-12 schema and every committed track definition.
- `check_repository.py`: checks local Markdown links and rejects tracked Python bytecode.

Future tools:

- UBX trace decoder
- GNSS session replay
- track-line editor/refiner
- log to CSV/GPX converter
- performance report generator
